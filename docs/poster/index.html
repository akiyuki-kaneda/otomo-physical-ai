忘却と対話の設計

このページについて

このページは、研究ポスター「忘却と対話の設計」の 補足情報と、ご意見の受付窓口です。

本研究では、介護の場面での観察記録をもとに、 本人の語りや意思を尊重する対話AIの設計を検討しています。

対話AIの設計内容は構想・仮説です。 その効果はまだ検証されていません。

研究の補足資料

設計仮説や参考資料は、内容を確認したうえで、 このページに掲載する予定です。
